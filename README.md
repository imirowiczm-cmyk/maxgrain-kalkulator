# Kalkulator suszenia kukurydzy – Max Grain

Kalkulator kosztu usługowego suszenia kukurydzy (stawka za tonoprocent, t%).
Jeden plik `index.html` – logo, style i skrypt są wbudowane.

- Koszt za tonę = stawka × (wilgotność przy dostawie − wilgotność docelowa)
- Masa po suszeniu = masa × (100 − W₁) / (100 − W₂)

Domyślne parametry (do potwierdzenia przez Max Grain): 14 zł/t%, docelowo 14%, VAT 8%.
